Overview

titledb is an automated Python-based tool for maintaining and updating title/version information stored in this repository.

The Python update script periodically retrieves the latest available information, processes it, and updates the repository's data files when changes are detected.

The repository is designed to run automatically on a daily schedule using Windows Task Scheduler.

This is being automated as the script from blawar is no longer updating https://github.com/blawar. It is a mix of an update from 16bit's repo https://github.com/16BitWonder/nx-versions/blob/master/versions.txt and AI generated script to mirror the results from blawar
